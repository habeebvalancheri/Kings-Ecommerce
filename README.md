Kings E-commerce Application Documentation

Project Overview

The Kings E-commerce Application is a full-fledged e-commerce platform developed to provide an online shopping experience with a variety of features for both customers and administrators.
The application was built using EJS, JavaScript, Node.js, MongoDB, and hosted on AWS Cloud Services for scalability and performance.

The primary goals of this project were:

To learn and understand key web development concepts, including JavaScript, Node.js, and MongoDB.
To explore e-commerce features like payment integration, user management, product management, and more.
To implement cloud hosting using AWS and gain hands-on experience with cloud services.
To receive industry expert feedback for improving the project's quality and deployment.

Key Features

1. Product Management

The system allows for seamless product management, including:

Adding new products with details such as name, description, price, images, and stock quantity.
Editing or removing existing products.
Categorizing products for better organization and easier search.

2. User Management

The application includes robust user management for both customers and administrators:

Users can register, log in, and update their profile information.
Admin users have access to a dashboard where they can manage users, products, orders, and sales reports.

3. Category Management

The admin can create and manage product categories to organize the product catalog efficiently. Categories help customers filter and search products more easily.

5. Dynamic Dashboard

The application features a dynamic admin dashboard that provides:

Sales charts showing real-time statistics about sales, revenue, and orders.
Custom reports for analyzing sales trends.
The ability to download sales reports in both Excel and PDF formats for offline analysis and reporting.

5. Payment Integration

Multiple payment options are available for users to complete their purchases:

Razorpay Integration: Secure online payment gateway for credit/debit card and UPI payments.
Wallet Payment: Allows users to make payments from their pre-loaded wallet balance.
Cash on Delivery (COD): Users can choose COD as a payment method for offline payments.

6. Address Management

Users can add, update, and delete their delivery addresses. The application allows customers to store multiple addresses for future use, making the checkout process faster.

7. Cloud Hosting on AWS

The application is hosted on AWS Cloud Services, leveraging the scalability and high availability of cloud infrastructure. Key AWS services used include:

AWS EC2 for hosting the Node.js server.
AWS S3 for storing product images and user-uploaded content.

8. Admin Dashboard Features

The admin dashboard allows for efficient management of the entire e-commerce platform, including:

Viewing and managing orders.
Monitoring user activity.
Generating and downloading sales reports.
Managing product categories and stock levels.

Technologies Used

EJS: Used for rendering dynamic HTML views on the frontend, providing a smooth, interactive user experience.

JavaScript: The core programming language used for both frontend and backend logic.

Node.js: Backend server framework used to handle requests, interact with MongoDB, and manage the application’s business logic.

MongoDB: A NoSQL database used to store and manage the application’s data, including user profiles, products, orders, and payment information.

Razorpay: Integrated payment gateway for handling secure online payments.

AWS: Cloud hosting for scalability, performance, and availability of the application. Key services include EC2, S3.

Git: Version control used to manage the project’s source code and collaboration.
